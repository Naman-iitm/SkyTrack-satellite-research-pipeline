# Contributing to SkyTrack

Thank you for your interest in contributing to SkyTrack.

SkyTrack is a research-oriented satellite metadata enrichment pipeline, and contributions that improve reliability, reproducibility, usability, documentation, and data quality are welcome.

## Ways to Contribute

You can contribute through:

* Bug reports
* Feature requests
* Documentation improvements
* Testing
* Data-source integrations
* Matching improvements
* Validation improvements
* UI improvements
* Performance improvements

## Before Opening an Issue

Please check existing issues first.

For bugs, include:

* What happened
* What you expected
* Steps to reproduce
* Input format
* Relevant error messages
* Python version
* Operating system

Do not include private credentials or sensitive data.

## Pull Requests

Before submitting a pull request:

1. Explain the problem being solved.
2. Keep the change focused.
3. Update documentation when necessary.
4. Add or update tests where appropriate.
5. Make sure the application still runs.
6. Avoid committing credentials or generated secrets.

## Research Data

Do not submit private, copyrighted, or restricted datasets unless redistribution is explicitly permitted.

When adding a new public data source, document:

* Source name
* Source URL
* Data format
* Access method
* Update frequency
* Relevant usage restrictions

## Code Quality

Please keep changes readable, maintainable, and consistent with the existing project structure.

Thank you for helping improve SkyTrack.
