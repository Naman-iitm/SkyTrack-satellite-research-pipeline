# Changelog

All notable changes to SkyTrack are documented here.

The format follows the principles of Semantic Versioning.

---

## [1.0.0] — 2026-08-18

### Added

* Initial public release of SkyTrack.
* CSV satellite dataset ingestion.
* Excel dataset ingestion.
* Manual satellite name input.
* Google Sheets integration.
* UCS Satellite Database enrichment.
* CelesTrak SATCAT enrichment.
* Wikipedia fallback enrichment.
* Launch vehicle reference database.
* Batch satellite processing.
* Automatic field mapping.
* Confidence scoring.
* Evidence logging.
* Manual review support.
* Structured research dataset generation.
* GPT-oriented dataset generation.
* Multi-sheet Excel export.
* Google Sheets export.
* Streamlit-based user interface.

### Notes

SkyTrack v1.0.0 establishes the initial research pipeline for satellite metadata enrichment and structured dataset generation.

Low-confidence or conflicting records should be manually verified before final research use.
